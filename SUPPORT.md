# Support Guide

Welcome to UniSearch support! This project is built to help students navigate the complex world of university admissions.

## Project Mission

UniSearch is more than just a database; it's a digital consultant. Built by a student from **Nazarbayev University**, the project draws from real-world experience to help you find the right institution, estimate your chances, and plan your academic future.

## How to get help

### 1. Documentation
Before asking a question, please check the following:
- [README.md](README.md) — For installation and general overview.
- [docs/](docs/) — For detailed design and architecture notes.

### 2. Frequently Asked Questions (FAQ)
We are currently building our FAQ based on community feedback. If you have a common question, it might already be discussed in [GitHub Issues](https://github.com/Muxlex/unisearch/issues).

### 3. Reporting Bugs
If you found a technical bug:
- Go to [GitHub Issues](https://github.com/Muxlex/unisearch/issues).
- Search for existing issues to avoid duplicates.
- Create a new issue using a clear title and description.

### 4. Data Corrections
If you find incorrect data about a university:
- Create a **GitHub Issue**.
- Provide the correct value.
- **Mandatory:** Include a link to the **official university website** or an official PDF as proof. We follow a strict "official-only" data policy.

### 5. General Questions
If you need help choosing a university or have a general question about the project:
- Create a GitHub Issue with the `question` label.
- Please be specific about your profile and interests.

## What we don't provide
- **Personalized Admission Services:** While UniSearch acts as a consultant tool, the maintainers do not provide individual coaching or "guaranteed" admission help.
- **Support for Unofficial Data:** We only support and maintain data that can be verified through official sources.

Thank you for using UniSearch!
