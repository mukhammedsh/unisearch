## Linked contract

The 2026-10-20 source refresh records agreement between both transfer fee pages at USD 100, the current CS MS English exemptions and the restriction on applicants already holding an external CS MS. Previous fact reviews remain in `review_history`. Published 2027–28 domestic first-year and transfer aid checklists preserve the 2025 tax year, separate-parent evidence and the undocumented-student FAFSA exception; the 2026–27 checklists remain historical. Resolved publication gaps use a `superseded` review status so the runtime keeps them in history rather than active uncertainty notices. Other researched unknowns concern unpublished future rates, applicant-specific or private instructions and unresolved official-source differences; they do not represent unfinished collection tasks.

`inventory-snapshot.json` preserves the public 2026-27 Bulletin display rows, including non-degree exclusions. Its configured university-hosted display uses public Coursedog metadata; the raw list is not proof that every restricted award is offered to a new applicant. Independently sourced offerings/configurations missing from the display remain in supplemental evidence rather than being discarded. `graduate-directory-snapshot.json` and `coterm-directory-snapshot.json` preserve exact named application tables. The separately labelled Stanford Bulletin link identifies the degree; a Program Website link can point to a related degree and must not override it.

`catalog.json` is a linked index. Resolve each fact's `evidence_file` and `original_id` for its complete value, conditions and exceptions. `original_scope`, source checked date and publication/review status preserve the dossier verbatim; the index normalizes explicitly known option and level aliases. Variant IDs and `parent_option_id` preserve specializations without inventing independent degrees. `application_classifications` keeps each evidence profile's classification rather than overwriting an earlier review. Differing classifications require a reasoned source review.

Source and procedure IDs are namespaced by dossier. Duplicated procedure names in different files do not prove the same application. Each option lists the researched procedure contexts and each procedure links back to its options. External nonprofessional directory contexts carry `shared_policy_context_ids` because the official directory explicitly points to central How to Apply; this bridge never transfers every central eligibility, fee, English or funding fact without its own conditions. Coterminal, internal and professional routes remain separate. Scope dimensions intersect; a fact with both option and procedure IDs belongs only to that option in that procedure.

`sources.json` retains the full original source records. HTTP/access state remains distinct from content review. `runtime-provenance.json` is historical input only; import date never refreshes a source review. `evidence_fingerprints` makes stale indexing detectable. `schema.json` documents the index, while `example.json` contains filled contrasts with resolved fact values for review. Neither activates runtime readers.
