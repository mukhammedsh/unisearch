# Accessibility

This page describes UniSearch's current accessibility goals and known limitations. It applies to the UniSearch website and its public user interface.

## Our commitment

We want people with different access needs to be able to explore universities and use UniSearch's tools. We consider accessibility as we design and update the interface, and we welcome reports when something gets in the way.

Our design guidance sets WCAG AA text contrast, visible keyboard focus, keyboard access, and support for reduced motion as goals. The shared interface includes a skip link to the main content, visible focus styles, and styles that respond to the operating system's reduced-motion preference. These measures are part of ongoing work; they do not mean that every page or interaction has been fully audited.

## Supported environments

UniSearch is a responsive web application intended for desktop and mobile browsers. We do not currently publish a verified support matrix for specific browsers, operating systems, or screen readers. If you report an accessibility issue, please include the browser and version, device or operating system, and assistive technology and version if applicable.

## Known limitations

We have not documented a comprehensive accessibility audit of the whole site, and we cannot claim that every page or workflow conforms to WCAG. Automated checks cover selected interface areas only. Accessibility issues may remain in particular pages, controls, languages, or browser and assistive-technology combinations.

## Report an accessibility barrier

Please [open a GitHub issue](https://github.com/mukhammedsh/unisearch/issues) and describe the page, what you were trying to do, what happened, and what you expected. Steps to reproduce are helpful. You can also email [info@unisearch.study](mailto:info@unisearch.study), especially if the report contains private information.

Please do not include passwords, account credentials, or private applicant or profile information in a public issue. A screenshot or short recording can help when it does not expose personal information.
