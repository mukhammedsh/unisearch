## 2026-09-27 - Expanded Sensitive Header and Credential Scrubbing in Observability Events
**Vulnerability:** The observability data scrubber (`_scrub_sensitive`) only checked specific key names and a narrow set of substrings (`token`, `secret`, `password`, `authorization`). Headers and payload fields containing session identifiers or API keys (such as `Set-Cookie`, `X-Api-Key`, `Authentication`, `session_id`, `user_credentials`) were passed unscrubbed into error reports and telemetry events.
**Learning:** Observability event structures include HTTP headers and arbitrary nested JSON payloads. Relying only on exact key matches or a minimal keyword list leaves common credentials like cookies, session IDs, and custom API key headers exposed in external telemetry platforms like Sentry.
**Prevention:** Maintain substring match rules for all credential types (`cookie`, `auth`, `session`, `credential`, `api_key`, `apikey`, `api-key`) in the central event scrubber, and write unit tests covering both request headers and nested payload fields.
