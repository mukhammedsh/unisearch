Privacy Policy

How UniSearch handles information, stores data locally on your device, and maintains security.

1. Core Principles & Data Minimization

UniSearch is built with a privacy-first mindset. Browsing our catalog does not require account registration, nor do we request national IDs, phone numbers, or payment credentials.

The platform supports two modes of operation: an anonymous guest mode (default) and an authenticated mode for cross-device profile synchronization.

2. Guest Mode & Client-Side Storage

When using UniSearch as a guest, your academic metrics and preferences remain strictly on your device inside browser storage (localStorage and sessionStorage). This includes:

  • Academic metrics (GPA, test scores such as SAT, ACT, IELTS, TOEFL, and others).
  • Declared academic fields of interest for personalized recommendations.
  • Shortlisted universities and recently viewed history.
  • Display preferences (light or dark mode, UI language).

You maintain full custody of these records. You can purge them at any time by clearing your browser cache or using the reset controls in settings.

3. Authentication via Third-Party Services (Google Sign-In) — In Development

This feature is currently under active development and is inactive in the current release. The guidelines below describe how user data will be handled once authentication is enabled.

To synchronize saved universities and academic inputs across multiple devices, UniSearch provides optional sign-in through Google (Google Sign-In / OAuth 2.0).

When authenticating via Google, our application receives only essential public profile details:

  • Email address — to uniquely identify your user profile.
  • Display name and profile picture — for display in the application navbar.
  • Unique Google account identifier.

UniSearch adheres to the Google API Services User Data Policy, including the Limited Use requirements. We never request or store your Google account password, and we do not sell or transfer Google user data to third parties or advertising brokers.

4. Algorithmic Recommendations & Server Processing

When utilizing smart ranking features like UniFit or exam validations, anonymous numerical metrics are transmitted over secure HTTPS to the UniSearch backend.

Calculations occur ephemerally in volatile memory (RAM) to return computed results. Your scores are not retained in persistent databases without your consent and are never tied to personal identifying records.

5. Technical Server Logs & Infrastructure Security

Standard HTTP network requests automatically log basic connection metadata: client IP address, User-Agent header, and request timestamp.

This information is processed solely to safeguard platform infrastructure, mitigate denial-of-service attempts, and enforce API rate limits. Server logs are routinely rotated and purged.

Interactive Map & External Assets: when browsing the catalog map, your browser fetches map tiles from OpenStreetMap servers and the Leaflet library via unpkg CDN. During these requests, these external services receive standard technical IP metadata to transmit visual map tiles. UniSearch never shares user profile inputs or academic metrics with external map providers.

6. Cookies & Tracking Technology

UniSearch does not deploy commercial marketing trackers, cross-site profiling pixels, or intrusive tracking scripts.

Functional storage tokens are utilized strictly to preserve your interface preferences (such as language and color theme).

7. User Rights & Data Erasure

In accordance with global privacy principles (including GDPR and CCPA guidelines), you retain full rights to your data and privacy.

For guest storage, clearing browser history completely removes all cached information. For synchronized accounts, you may revoke UniSearch permissions in your Google Security settings or request account deletion via support.
