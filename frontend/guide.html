UniSearch Guide

How to use UniSearch and understand scores

This page explains key terms used in UniSearch: UniFit ranking logic, UniChance probability, UniMentor assistance, admission tracks, score types, language proofs, and budget behavior.

UniFit (AI Smart Sort)

UniFit is the ranking mode used in the Universities page when sort is set to AI Smart Sort. It is designed to prioritize realistic options, not only famous names. In practical terms, this means the score combines three dimensions that are visible in your product behavior: academic feasibility from profile data, financial fit from yearly budget and university costs, and prestige signals such as rank and selectivity.

The budget-prestige slider changes weighting, but it does not ignore constraints. Even if the slider is moved to prestige, tracks that are far outside your profile are still penalized. Likewise, if slider priority is budget, the algorithm still keeps academically suitable options above choices that are cheap but unrealistic for admission. This prevents unstable recommendations and keeps output useful for real application planning.

The model evaluates admission tracks separately when track data exists. That is why one university can look stronger than another for a specific student even if overall rank is lower. A track with matching exam thresholds and language conditions will usually score above a track that has better reputation but poor eligibility match.

Because your profile can change at any moment, UniFit results are intentionally dynamic. Updating exam scores, languages, or budget should immediately change ordering. This is expected and correct behavior: the goal is a personalized shortlist that reflects current data, not a fixed static ranking.

UniChance (0-100 Admission Probability)

UniChance provides a probability estimate from 0 to 100 for each university and, when available, for each admission track. It should be read as a decision-support indicator rather than a guarantee. The score helps compare options by feasibility and identify which paths are competitive, borderline, or low-probability.

The estimate is calculated from profile and track data already present in the platform: minimum requirements, typical admitted scores, language rules, acceptance context, and affordability signals. If your profile does not satisfy strict minimums, probability decreases strongly. If your profile is around typical admitted values, probability generally rises.

Recommended interpretation in this product is straightforward: 80-100 means high chance, 60-79 means good chance, 40-59 means moderate chance, and below 40 means low chance. These ranges are useful for planning application strategy. A balanced plan usually includes safer options, target options, and a limited number of ambitious options.

The “Best Track” output is important: it highlights the strongest path inside one university. Students often focus on one main route and miss alternative tracks with better fit. This section helps reveal those alternatives and can materially improve shortlisting quality.

Gap Coach (Readiness + Action Plan)

Gap Coach is shown in University -> Admission and explains exactly what is missing for your best track right now. It is designed as a practical checklist: not only score output, but concrete next steps.

The panel includes three parts: current readiness score (0-100), top blockers (academic, language, budget), and a priority action plan. This helps users understand what to fix first instead of guessing.

Readiness status is interpreted as: safe (strong fit), borderline (possible but risky), and at-risk (key requirements not met). This is guidance, not a guarantee of admission.

The panel uses stale-while-revalidate behavior: cached result appears immediately for fast UX, then the app refreshes in background and updates if server data changed. After profile edits, Gap Coach is re-checked automatically.

UniMentor (AI Chat Consultant)

UniMentor is intended for side questions that are useful for applicants but are not always available in the local dataset. The primary behavior is database-first: when information exists in UniSearch data, answers should rely on that data and present it clearly.

Typical high-value usage is clarification. For example: understanding track differences, language requirement logic, cost composition, scholarship notes, or what profile changes can improve fit. This reduces confusion and helps users convert ranking output into an actionable application plan.

When online mode is enabled, UniMentor may include external context for questions outside core dataset coverage. This can be useful for institutional background questions and similar side topics. In such cases, answers should stay concise and transparent about source context.

Best practice for users is to use mentor output as guidance, then verify critical final details on official university pages before submitting applications. UniSearch helps narrow and explain options; official admissions documents remain the authoritative source for final rules and deadlines.

Admission Track Terms

An admission track is a specific pathway into a program. One university can publish several tracks with different minimum scores, language proofs, scholarship conditions, and expected costs. In UniSearch, these tracks are intentionally separated because applicant outcomes often depend on choosing the right track, not just the right university.

Requirements represent the minimum threshold for eligibility. Meeting only minimums may keep an application valid but does not automatically indicate strong competitiveness. Real Average (Admitted) provides a better practical target where available, because it reflects profile levels observed among admitted students.

Language rules are handled as explicit logic. In mode any, satisfying one listed proof is enough. In mode all, every listed language condition must be satisfied. This difference is significant and can change both ranking and probability outcomes.

Track-level scholarships and aid can modify financial viability. In some cases grants partially offset tuition; in others they can be substantial. For shortlist planning, compare both gross and effective cost after aid assumptions, then prioritize tracks that are both feasible and sustainable.

Exam Basics (Admissions)

Admissions generally evaluate two different dimensions: academic preparation and language readiness. Academic exams measure subject performance; language evidence confirms that the applicant can study in the program’s teaching language. Most universities combine these dimensions with transcripts and, in some cases, additional materials.

National exams are commonly used in domestic systems, while international pathways can include exams such as SAT, ACT, AP, IB, or institution-specific alternatives. UniSearch does not assume one universal exam model; it maps each track’s stated requirements and compares them to the profile entered by the user.

Language certificates are especially important for international applicants. A program may accept several exam options and define minimum thresholds for one or more exams. Some tracks also allow native-language conditions. Because these rules differ by track, applicants should avoid broad assumptions and read track-level requirements carefully.

For strategy, treat exam planning as timeline management: confirm minimums first, then target typical admitted levels where possible, then distribute applications by risk level. This approach is usually more effective than applying only to highly selective options with weak profile alignment.
